# សាលាអន្តរជាតិ ហេមតុន (Hampton International School)
### ឃ្លាំងផ្ទុកមេរៀន វីដេអូ និងកម្រងលំហាត់ សម្រាប់គ្រូ សិស្ស មាតាបិតា និង Admin

គេហទំព័រនេះត្រូវបានបង្កើតឡើងសម្រាប់ **សាលាអន្តរជាតិ ហេមតុន (Hampton International School)** ដោយបានបំពាក់ប្រព័ន្ធ **Login & Multi-User Authentication** ជាមួយការកំណត់សិទ្ធិ (Role-Based Permissions) ច្បាស់លាស់៖ **Admin (អភិបាល), Teacher (គ្រូបង្រៀន), Student (សិស្សានុសិស្ស), និង Parent (មាតាបិតា)**។

## 👥 តួនាទី និងសិទ្ធិប្រើប្រាស់ (Roles & Permissions)

| តួនាទី (Role) | គណនីគំរូ | ពាក្យសម្ងាត់ | សិទ្ធិប្រើប្រាស់ (Permissions) |
|---|---|---|---|
| 🛡️ **Admin (អភិបាល)** | `admin` | `admin123` | **មានសិទ្ធិធ្វើអ្វីទាំងអស់ (Full Super-Admin)**៖<br>• គ្រប់គ្រងអ្នកប្រើប្រាស់ (បង្កើត User ថ្មី, កែប្រែ Role, លុប User, ប្តូរ Password)<br>• បង្កើត, កែប្រែ, និងលុបមេរៀន/លំហាត់ទាំងអស់ក្នុងប្រព័ន្ធ<br>• ទាញយក និងបញ្ចូលទិន្នន័យបម្រុងទុក (Full Backup / Restore JSON)<br>• មើលស្ថិតិ និងគ្រប់គ្រងប្រព័ន្ធទាំងមូល |
| 👨‍🏫 **Teacher (គ្រូបង្រៀន)** | `teacher` | `teacher123` | • បង្កើតមេរៀនទ្រឹស្តី និងកម្រងលំហាត់ថ្មីៗ<br>• បង្កើតសំណួរ Quiz អន្តរកម្ម និងភ្ជាប់វីដេអូ<br>• កែប្រែ ឬលុបមេរៀនដែលខ្លួនបានបង្កើត<br>• មើលពិន្ទុ និងការអនុវត្តរបស់សិស្ស |
| 🎓 **Student (សិស្សានុសិស្ស)** | `student` | `student123` | • ចូលអានមេរៀន និងទស្សនាវីដេអូពន្យល់គ្រប់កម្រិតថ្នាក់<br>• ធ្វើលំហាត់អនុវត្ត (Interactive Quizzes) និងទទួលបានពិន្ទុភ្លាមៗ<br>• មើលដំណោះស្រាយពន្យល់លម្អិតមួយជំហានៗ<br>• រក្សាទុកមេរៀនដែលចូលចិត្ត (Bookmarks) |

## ⚡ មុខងារពិសេសៗនៃការគ្រប់គ្រង User

1. **ប៊ូតុងចុចចូលរហ័ស (1-Click Quick Demo Login)**៖
   - នៅលើរបារខាងលើបង្អស់ និងក្នុងផ្ទាំង Login មានប៊ូតុងចុចចូលគណនីគំរូភ្លាមៗ (Admin, គ្រូ, សិស្ស, មាតាបិតា) សម្រាប់លោកអ្នកងាយស្រួលសាកល្បងសិទ្ធិនីមួយៗដោយមិនបាច់វាយអក្សរ។
2. **ការបង្កើត User ថ្មីបានច្រើន (Unlimited Users)**៖
   - អ្នកប្រើប្រាស់ទូទៅអាចចុចលើពាក្យ **«ចុះឈ្មោះ»** ដើម្បីបង្កើតគណនីផ្ទាល់ខ្លួន។
   - **Admin** អាចចូលទៅកាន់ **«គ្រប់គ្រង User»** ដើម្បីបង្កើតគណនីថ្មី និងកំណត់សិទ្ធិ (Role) ឱ្យទៅជា Admin, គ្រូ, សិស្ស ឬមាតាបិតា ព្រមទាំងកំណត់កម្រិតថ្នាក់បានតាមចិត្ត។
3. **ការកែប្រែសិទ្ធិ (Change User Role)**៖
   - Admin អាចផ្លាស់ប្តូរសិទ្ធិរបស់អ្នកប្រើប្រាស់ណាម្នាក់ពីសិស្សទៅជាគ្រូ ឬពីគ្រូទៅជា Admin បានភ្លាមៗ។
