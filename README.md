# សាលាអន្តរជាតិ ហេមតុន — ថ្នាក់រៀនអនឡាញ

គេហទំព័រសាមញ្ញសម្រាប់ **គ្រូ សិស្ស មាតាបិតា និង Admin**៖

| តួនាទី | អាចធ្វើអ្វីបាន |
|---|---|
| **Admin** | បង្កើតគណនីគ្រូ សិស្ស មាតាបិតា • ដាក់/កែ/លុបមេរៀនទាំងអស់ • មើលកំណត់ត្រាសិស្សទាំងអស់ |
| **គ្រូ** | ដាក់មេរៀន (វីដេអូ YouTube + ឯកសារ PDF/Word ពី Google Drive) • បង្កើតគណនីសិស្ស និងមាតាបិតា • ភ្ជាប់មាតាបិតាជាមួយកូន • មើលកំណត់ត្រាសិស្ស និងទាញយក CSV (Excel) |
| **សិស្ស** | មើលមេរៀនតាមថ្នាក់ខ្លួន • មើលវីដេអូ • មើល/ទាញយកឯកសារ • ចុច «ខ្ញុំរៀនរួចហើយ» • មើលកំណត់ត្រារបស់ខ្លួន |
| **មាតាបិតា** | មើលកំណត់ត្រារៀនរបស់កូន (រៀនរួចប៉ុន្មាន, រយៈពេលរៀន, ថ្ងៃចូលរៀនចុងក្រោយ) • មើលមេរៀន |

**កំណត់ត្រាសិស្ស** កត់ត្រាស្វ័យប្រវត្តិ៖ ពេលសិស្សបើកមេរៀន, ចំនួនដងបើក, រយៈពេលរៀន (រាប់តែពេលកំពុងមើល), និងមេរៀនដែលរៀនរួច។

ទិន្នន័យទាំងអស់រក្សាទុកក្នុង **Supabase** (Database លើ Internet, Server នៅ Singapore) ដូច្នេះគ្រូដាក់មេរៀនពីកុំព្យូទ័រ សិស្សមើលបានពីទូរស័ព្ទនៅផ្ទះភ្លាមៗ។

## 🔑 ចូលលើកដំបូង

- Username: `admin`
- ពាក្យសម្ងាត់៖ (ឃើញក្នុងសារពី Claude)
- **សូមប្តូរពាក្យសម្ងាត់ភ្លាម**៖ ចុចឈ្មោះខាងស្តាំលើ → «ប្តូរពាក្យសម្ងាត់»

## 📋 ជំហានប្រើប្រាស់

1. Admin ចូល → ផ្ទាំង **គណនីអ្នកប្រើ** → បង្កើតគណនីគ្រូ
2. គ្រូចូល → បង្កើតគណនីសិស្ស (ជ្រើសថ្នាក់) និងមាតាបិតា → ចុចរូប 🔗 ដើម្បីភ្ជាប់មាតាបិតាជាមួយកូន
3. គ្រូ → ផ្ទាំង **មេរៀន** → «បង្កើតមេរៀនថ្មី» → បិទភ្ជាប់ Link YouTube និង Link Google Drive
4. ផ្តល់ Username & ពាក្យសម្ងាត់ (ប្រព័ន្ធបង្ហាញឱ្យចម្លង) ទៅសិស្ស និងមាតាបិតា

> ⚠️ ឯកសារ Google Drive ត្រូវកំណត់ **Share → General access → Anyone with the link** ទើបសិស្សមើលបាន។

## 🌐 ដាក់គេហទំព័រលើ Internet (ឥតគិតថ្លៃ)

**វិធីងាយបំផុត — Netlify Drop**
1. ចូល https://app.netlify.com/drop
2. អូស folder នេះទាំងមូលទម្លាក់ចូល → ទទួលបាន Link ភ្លាមៗ

**ឬ GitHub Pages** — Upload ឯកសារទាំងអស់ទៅ Repository → Settings → Pages → Branch `main` → Save

> ការបើក `index.html` ដោយ Double-click ក៏ដំណើរការដែរ (ត្រូវការ Internet ដើម្បីភ្ជាប់ Database)។

## 📁 រចនាសម្ព័ន្ធឯកសារ

```
index.html          ទំព័រមេ
js/config.js        ការកំណត់ (ឈ្មោះសាលា, ថ្នាក់, មុខវិជ្ជា, Supabase)
js/app.js           កម្មវិធី
css/app.css         ស្ទីល (បង្កើតពី css/app.input.css ដោយ Tailwind)
vendor/             Fonts ខ្មែរ, Icons, Supabase (មិនពឹង CDN)
images/logo.png     Logo សាលា
```

- **បន្ថែមថ្នាក់ ឬមុខវិជ្ជា**៖ កែក្នុង `js/config.js`
- **បើកែ class ក្នុង HTML/JS** ត្រូវបង្កើត CSS ឡើងវិញ៖ `npx tailwindcss@3 -i css/app.input.css -o css/app.css --minify`
