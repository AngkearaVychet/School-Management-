| តួនាទី | អាចធ្វើអ្វីបាន |
|---|---|
| **Admin ប្រព័ន្ធ** | ម្ចាស់ប្រព័ន្ធ (គណនី `admin`) • សិទ្ធិគ្រប់យ៉ាង • តែម្នាក់គត់ដែលបង្កើត/កែ/លុប **អ្នកគ្រប់គ្រង** បាន |

| **ប្រធានផ្នែក** | Admin ជ្រើសថ្នាក់ឱ្យគ្រប់គ្រង (ឧ. ថ្នាក់ទី១–៦ ឬ K1–GEP 3) • បង្កើត/កែ/លុបមេរៀន និងកិច្ចការទាំងអស់ក្នុងថ្នាក់ផ្នែកខ្លួន • មើលកំណត់ត្រាសិស្សតែក្នុងផ្នែក • បង្កើតគណនីគ្រូ សិស្ស (ក្នុងផ្នែក) និងមាតាបិតា |
| **គ្រូ** | Admin/ប្រធានផ្នែក ធីកថ្នាក់ដែលគ្រូបង្រៀន → គ្រូឃើញតែថ្នាក់ទាំងនោះពេលដាក់មេរៀន បង្កើតសិស្ស និងមើលកំណត់ត្រា • ដាក់មេរៀន (វីដេអូ YouTube + ឯកសារ PDF/Word ពី Google Drive) • បង្កើតគណនីសិស្ស និងមាតាបិតា • ភ្ជាប់មាតាបិតាជាមួយកូន • មើលកំណត់ត្រាសិស្ស និងទាញយក CSV (Excel) |
| **សិស្ស** | មើលមេរៀនតាមថ្នាក់ខ្លួន • មើលវីដេអូ • មើល/ទាញយកឯកសារ • ចុច «ខ្ញុំរៀនរួចហើយ» • មើលកំណត់ត្រារបស់ខ្លួន |
| **មាតាបិតា** | មើលកំណត់ត្រារៀនរបស់កូន (រៀនរួចប៉ុន្មាន, រយៈពេលរៀន, ថ្ងៃចូលរៀនចុងក្រោយ) • មើលមេរៀន |

## ✍️ កិច្ចការអន្តរកម្ម (ដូច Liveworksheets)

ផ្ទាំង **កិច្ចការ**៖ គ្រូ Upload រូប (JPG/PNG) ឬ PDF សន្លឹកកិច្ចការ ហើយគូសប្រអប់លើរូប៖

| ប្រអប់ | របៀបប្រើ |
|---|---|
| ✏️ វាយចម្លើយ | សិស្សវាយចម្លើយ។ ចម្លើយត្រូវច្រើនបាន បំបែកដោយ `/` (ឧ. `5/five`) |
| 🔽 ជ្រើសចម្លើយ | Dropdown — វាយជម្រើស `ក / ខ / គ` រួចជ្រើសចម្លើយត្រូវ |
| ☑️ ធីក | ធីកលើ «ប្រអប់នេះត្រូវធីក» សម្រាប់ចម្លើយត្រូវ (ប្រអប់មិនធីក = សិស្សមិនត្រូវធីក) |
| ✋ ពាក្យសម្រាប់អូស | គូសលើពាក្យនៅក្នុងរូប ហើយវាយពាក្យនោះ |
| 📥 ចន្លោះទម្លាក់ | គូសលើចន្លោះ ហើយជ្រើសពាក្យដែលត្រូវទម្លាក់ចូល |
| ● ចំណុចផ្គូផ្គង (សំណួរ) / ◎ ចំណុចផ្គូផ្គង (ចម្លើយ) | **គូសបន្ទាត់ផ្គូផ្គង** — ដាក់ ◎ ជាប់ចម្លើយនីមួយៗ (ប្រព័ន្ធដាក់ឈ្មោះ ក ខ គ ...), ដាក់ ● ជាប់សំណួរ ហើយជ្រើសថា ● នេះភ្ជាប់ទៅ ◎ ណា។ សិស្សអូសបន្ទាត់ពីចំណុចមួយទៅចំណុចម្ខាងទៀត (ឬចុចម្តងមួយ) |
| 🔊 សំឡេង | **ស្តាប់** — Upload ឯកសារ MP3/M4A (≤ 20MB), ចុច «ថតសំឡេង» ថតដោយផ្ទាល់ពី Microphone, ឬបិទភ្ជាប់ Link Google Drive។ សិស្សចុចប៊ូតុងដើម្បីស្តាប់ (មិនគិតពិន្ទុ — ប្រើជាមួយប្រអប់ចម្លើយផ្សេងទៀត) |
| 🪪 ឈ្មោះសិស្ស / 📅 កាលបរិច្ឆេទ | គូសលើ «ឈ្មោះ៖ .....» និង «កាលបរិច្ឆេទ៖ .....» — ប្រព័ន្ធសរសេរឈ្មោះសិស្ស និងថ្ងៃធ្វើ ដោយស្វ័យប្រវត្តិ (មិនគិតពិន្ទុ) |

- ចុច **សាកល្បង** ដើម្បីធ្វើដូចសិស្ស មុនរក្សាទុក
- សិស្សចុច **បញ្ចប់** → ឃើញពិន្ទុភ្លាម (ត្រូវ = បៃតង, ខុស = ក្រហម + ចម្លើយត្រូវ)
- ចម្លើយត្រូវលាក់ក្នុង Database — សិស្សមើលលួចមិនបាន។ ការដាក់ពិន្ទុធ្វើនៅ Server
- គ្រូចុច **លទ្ធផល** ដើម្បីមើលពិន្ទុ និងចម្លើយសិស្សម្នាក់ៗ, អ្នកណាមិនទាន់ធ្វើ
- ពិន្ទុកិច្ចការបង្ហាញក្នុង «កំណត់ត្រា» របស់សិស្ស និងមាតាបិតា ហើយក្នុង CSV

**កំណត់ត្រាសិស្ស** កត់ត្រាស្វ័យប្រវត្តិ៖ ពេលសិស្សបើកមេរៀន, ចំនួនដងបើក, រយៈពេលរៀន (រាប់តែពេលកំពុងមើល), និងមេរៀនដែលរៀនរួច។

ទិន្នន័យទាំងអស់រក្សាទុកក្នុង **Supabase** (Database លើ Internet, Server នៅ Singapore) ដូច្នេះគ្រូដាក់មេរៀនពីកុំព្យូទ័រ សិស្សមើលបានពីទូរស័ព្ទនៅផ្ទះភ្លាមៗ។

## 🔑 ចូលលើកដំបូង

- Username: `admin`
- ពាក្យសម្ងាត់៖ (ឃើញក្នុងសារពី Claude)
- **សូមប្តូរពាក្យសម្ងាត់ភ្លាម**៖ ចុចឈ្មោះខាងស្តាំលើ → «ប្តូរពាក្យសម្ងាត់»

## 📋 ជំហានប្រើប្រាស់

1. Admin ចូល → ផ្ទាំង **គណនីអ្នកប្រើ** → បង្កើតគណនីគ្រូ
2. គ្រូចូល → បង្កើតគណនីសិស្ស (ជ្រើសថ្នាក់) និងមាតាបិតា → ចុចរូប 🔗 ដើម្បីភ្ជាប់មាតាបិតាជាមួយកូន
3. គ្រូ → ផ្ទាំង **មេរៀន** → «បង្កើតមេរៀនថ្មី» → បិទភ្ជាប់ Link YouTube និង Link Google Drive
4. ផ្តល់ Username & ពាក្យសម្ងាត់ (ប្រព័ន្ធបង្ហាញឱ្យចម្លង) ទៅសិស្ស និងមាតាបិតា

> ⚠️ ឯកសារ Google Drive ត្រូវកំណត់ **Share → General access → Anyone with the link** ទើបសិស្សមើលបាន។

## 🌐 ដាក់គេហទំព័រលើ Internet (ឥតគិតថ្លៃ)

**វិធីងាយបំផុត — Netlify Drop**
1. ចូល https://app.netlify.com/drop
2. អូស folder នេះទាំងមូលទម្លាក់ចូល → ទទួលបាន Link ភ្លាមៗ

**ឬ GitHub Pages** — Upload ឯកសារទាំងអស់ទៅ Repository → Settings → Pages → Branch `main` → Save

> ការបើក `index.html` ដោយ Double-click ក៏ដំណើរការដែរ (ត្រូវការ Internet ដើម្បីភ្ជាប់ Database)។

## 📁 រចនាសម្ព័ន្ធឯកសារ

```
index.html          ទំព័រមេ
js/config.js        ការកំណត់ (ឈ្មោះសាលា, ថ្នាក់, មុខវិជ្ជា, Supabase)
js/app.js           កម្មវិធី (មេរៀន, កំណត់ត្រា, គណនី)
js/worksheets.js    កិច្ចការអន្តរកម្ម
css/app.css         ស្ទីល (បង្កើតពី css/app.input.css ដោយ Tailwind)
vendor/             Fonts ខ្មែរ, Icons, Supabase, PDF.js (មិនពឹង CDN)
images/logo.png     Logo សាលា
```

- **បន្ថែមថ្នាក់ ឬមុខវិជ្ជា**៖ កែក្នុង `js/config.js`
- **បើកែ class ក្នុង HTML/JS** ត្រូវបង្កើត CSS ឡើងវិញ៖ `npx tailwindcss@3 -i css/app.input.css -o css/app.css --minify`
