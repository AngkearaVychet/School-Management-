# សាលាអន្តរជាតិ ហេមតុន (Hampton International School)
### ប្រព័ន្ធគ្រប់គ្រងសាលា ឃ្លាំងមេរៀន ព្រឹត្តិបត្រពិន្ទុ កាតសិស្ស ប័ណ្ណសរសើរ និងហិរញ្ញវត្ថុ រួមបញ្ចូលតែមួយ (Unified School System)

ប្រព័ន្ធនេះត្រូវបានបង្កើតឡើងសម្រាប់ **សាលាអន្តរជាតិ ហេមតុន (Hampton International School)** ដោយបានច្របាច់បញ្ចូលគ្នានូវរាល់មុខងារសំខាន់ៗទាំងអស់របស់សាលាឱ្យទៅជា **ប្រព័ន្ធតែមួយ (Unified Single-Page Application)** ដំណើរការបានទាំង Offline ក្នុងកុំព្យូទ័រ (មិនបាច់ប្រើ Internet ឬ Database Server) និង Online លើ Web Hosting (cPanel / Apache / VPS ជាមួយ PHP 7.4+ និង SQLite)។

## 🌟 សមាសភាគសំខាន់ៗដែលបានច្របាច់បញ្ចូលគ្នា (Unified Modules)

### ១. ឃ្លាំងមេរៀន និងកម្រងលំហាត់ឌីជីថល (Learning Hub)
* **ឃ្លាំងមេរៀន & វីដេអូ (`lessons`)**៖ ផ្ទុកមេរៀនទ្រឹស្តី វីដេអូពន្យល់ពី YouTube/HTML5 រូបមន្តគណិតវិទ្យា (KaTeX) សេចក្តីសង្ខេប និងឯកសារ PDF ទាញយក។
* **កម្រងលំហាត់អន្តរកម្ម (`quizzes`)**៖ សិស្សអាចចូលធ្វើតេស្តពហុជ្រើសរើស (Multiple Choice) ទទួលបានពិន្ទុភ្លាមៗ ព្រមទាំងការពន្យល់ដំណោះស្រាយលម្អិតមួយជំហានៗ។
* **ទម្រង់បង្កើតមេរៀន & សំណួរ Quiz**៖ គ្រូ និង Admin អាចបង្កើតមេរៀន និងសំណួរតេស្តថ្មីៗដោយផ្ទាល់។

### ២. ការគ្រប់គ្រងការសិក្សា និងសិស្ស (Academic Suite)
* **បញ្ចូល និងគណនាពិន្ទុ (`scores`)**៖ តារាងពិន្ទុរចនាបែប Ledger ស្រង់មធ្យមភាគ ចំណាត់ថ្នាក់ និទ្ទេស (A, B, C, D, E, F ឬ ល្អ, ល្អបង្គួរ, មធ្យម, ខ្សោយ) ដោយស្វ័យប្រវត្តិ។
* **វត្តមានសិស្ស (`attendance`)**៖ ស្រង់វត្តមានប្រចាំថ្ងៃ (វត្តមាន, ច្បាប់, ឥតច្បាប់, យឺត) និងសរុបប្រចាំខែ។
* **បញ្ជីឈ្មោះសិស្ស (`students`)**៖ កត់ត្រាព័ត៌មានសិស្ស ឈ្មោះខ្មែរ ឈ្មោះឡាតាំង ភេទ ថ្ងៃខែឆ្នាំកំណើត និងរូបថត ៣×៤។
* **ព្រឹត្តិបត្រពិន្ទុសិស្ស (`report`)**៖ បោះពុម្ពព្រឹត្តិបត្របុគ្គលម្នាក់ៗ ទាញយកជា PDF ឬ JPG ក្រដាស A4 ស្ដង់ដារ។
* **តារាងបិទផ្សាយលទ្ធផល (`notice`)**៖ តារាងពិន្ទុសម្រាប់បិទផ្សាយក្នុងថ្នាក់រៀន។
* **តារាងកិត្តិយស (`honor`)**៖ បង្ហាញសិស្សឆ្នើមលេខ១ ដល់លេខ៥ ប្រចាំខែ ភ្ជាប់ជាមួយរូបថតសិស្ស។
* **កាតសម្គាល់ខ្លួនសិស្ស (`idcard`)**៖ បង្កើតកាតសិស្សស្វ័យប្រវត្តិតាម **គំរូផ្លូវការរបស់សាលា ហេមតុន (Hampton ID Template)** ទាញយកជា PDF (៩ កាត/ទំព័រ A4) ឬ JPG។
* **ប័ណ្ណសរសើរសិស្សពូកែ (`cert`)**៖ បោះពុម្ពប័ណ្ណសរសើរផ្លូវការតាម **គំរូប័ណ្ណរបស់សាលា ហេមតុន (Hampton Certificate Template)** ចំនួន ២ ប័ណ្ណលើក្រដាស A4 មួយសន្លឹក។
* **ត្រា និងហត្ថលេខាឌីជីថល (`seal`)**៖ ថតរូបត្រាសាលា និងហត្ថលេខានាយក/គ្រូ ប្រព័ន្ធនឹងលុបផ្ទៃក្រដាសចេញដោយស្វ័យប្រវត្តិ ហើយបោះលើរាល់ឯកសារដែលព្រីនចេញ។
* **ថ្នាក់ និងមុខវិជ្ជា (`settings`)**៖ កំណត់មុខវិជ្ជា កម្រិតសិក្សា ព័ត៌មានសាលា និងគ្រប់គ្រងច្រើនសាខា (Multi-Branch)។

### ៣. ប្រព័ន្ធហិរញ្ញវត្ថុសាលា (School Finance Suite)
* **របាយការណ៍ហិរញ្ញវត្ថុប្រចាំខែ (`fdash`)**៖ ចំណូល ចំណាយ ចំណេញ/ខាត ចលនាសាច់ប្រាក់ក្នុងដៃ និងធនាគារ ទាញយកជា PDF/JPG មួយទំព័រ A4។
* **កត់ត្រាចំណូល (`fin_in`)**៖ កត់ត្រាប្រចាំថ្ងៃ បង្កាន់ដៃទទួលប្រាក់ ឈ្មោះអ្នកបង់ ប្រភេទចំណូល និងវិធីបង់ប្រាក់។
* **កត់ត្រាចំណាយ (`fin_out`)**៖ ថ្លៃជួលអគារ ទឹក ភ្លើង អ៊ីនធឺណិត សម្ភារៈការិយាល័យ ឯកសណ្ឋាន ជួសជុល និងសម្អាត។
* **បើកប្រាក់ខែបុគ្គលិក & គ្រូ (`fin_pay`)**៖ ប្រាក់ខែគោល ប្រាក់ឧបត្ថម្ភ ប្រាក់រង្វាន់ ពន្ធ ប.ស.ស. កាត់កង ប្រាក់ខែសុទ្ធ និងប៊ូតុងចម្លងពីខែមុន។
* **តាមដានថ្លៃសិក្សា (`fin_fee`)**៖ បញ្ជីសិស្ស ថ្លៃសិក្សាត្រូវបង់ ការបញ្ចុះតម្លៃ ប្រាក់បានបង់ និងសមតុល្យនៅខ្វះ។
* **បញ្ជីសិស្សជំពាក់ថ្លៃសិក្សា (`fin_debt`)**៖ សិស្សមិនទាន់បង់ ឬបង់ខ្វះ ចំនួនប្រាក់ជំពាក់ និងលេខទូរស័ព្ទអាណាព្យាបាលសម្រាប់ទាក់ទង។
* **សង្ខេបប្រចាំឆ្នាំ (`fin_year`)**៖ តារាងប្រៀបធៀប ១២ ខែក្បែរគ្នា ព្រមទាំងក្រាហ្វ SVG វិភាគចំណូល-ចំណាយ និងទាញយកជា Excel។
* **ការកំណត់ហិរញ្ញវត្ថុ & នាំចូល Excel (`fin_set`)**៖ កំណត់អត្រាប្ដូរប្រាក់ (៛ / $1) សមតុល្យដើមឆ្នាំ បញ្ជីជម្រើស និងប៊ូតុងនាំចូលឯកសារ Excel ហិរញ្ញវត្ថុចាស់។

## 👥 តួនាទី និងសិទ្ធិប្រើប្រាស់ (Role-Based Permissions)

| តួនាទី | សិទ្ធិប្រើប្រាស់ក្នុងប្រព័ន្ធ |
|---|---|
| 🛡️ **Admin (អ្នកគ្រប់គ្រង)** | **មានសិទ្ធិពេញលេញលើអ្វីៗទាំងអស់**៖ គ្រប់គ្រងអ្នកប្រើប្រាស់ ថ្នាក់ មុខវិជ្ជា ពិន្ទុ វត្តមាន ឃ្លាំងមេរៀន លំហាត់ កាតសិស្ស ប័ណ្ណសរសើរ និងហិរញ្ញវត្ថុទាំងអស់ |
| 👨‍🏫 **Teacher (គ្រូបង្រៀន)** | មើលនិងបញ្ចូលពិន្ទុ ស្រង់វត្តមាន បញ្ជីសិស្ស ចេញព្រឹត្តិបត្រ តារាងកិត្តិយស កាតសិស្ស ប័ណ្ណសរសើរ និងបង្កើត/កែប្រែមេរៀន និងលំហាត់ |
| 🎓 **Student (សិស្ស)** | ចូលរៀនមេរៀន ទស្សនាវីដេអូ ធ្វើលំហាត់ Quiz អន្តរកម្ម និងមើលព្រឹត្តិបត្រពិន្ទុផ្ទាល់ខ្លួន |
| 👨‍👩‍👧 **Parent (មាតាបិតា)** | តាមដានវត្តមាន ពិន្ទុ និងលទ្ធផលសិក្សារបស់កូន មើលមេរៀន និងទាញយកសន្លឹកកិច្ចការទៅផ្ទះ |
| 💼 **Accountant (គណនេយ្យករ)** | គ្រប់គ្រងផ្នែកហិរញ្ញវត្ថុទាំងមូល (ចំណូល ចំណាយ ប្រាក់ខែ ថ្លៃសិក្សា សិស្សជំពាក់ និងរបាយការណ៍) |

## 🚀 របៀបបើកដំណើរការ (Deployment & Running)

### ជម្រើសទី១៖ ដំណើរការលើកុំព្យូទ័រ (Offline / Standalone)
* គ្រាន់តែ **Double-Click** លើឯកសារ `index.html` ដើម្បីបើកក្នុង Web Browser ណាមួយ (Chrome, Edge, Firefox, Brave)។
* ឬដំណើរការ Local Web Server តាម PowerShell៖
  ```powershell
  powershell -ExecutionPolicy Bypass -File .\Start-Server.ps1
  ```

### ជម្រើសទី២៖ ដំណើរការលើ Web Hosting (cPanel / Apache / VPS)

2. ធានាថា Hosting ដំណើរការ **PHP 7.4+** ជាមួយ extension **pdo_sqlite** (មានស្រាប់លើ cPanel ស្ទើរតែទាំងអស់)។
3. បើកមើលតាម Browser (`https://domain.com/`)។ ប្រព័ន្ធនឹងភ្ជាប់ទៅកាន់ `api.php` និងបង្កើតមូលដ្ឋានទិន្នន័យ SQLite ស្វ័យប្រវត្តិ!
